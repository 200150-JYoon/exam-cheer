# 사이트 설계도(PRD) — 우리 아이 시험기간 응원 사이트

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
시험 공부하는 우리 아이가 남은 시험 일정과 엄마의 오늘 응원 한마디를 보고, 오늘 공부한 과목과 기분 한 단어를 남기는 응원 사이트.

## 2. 사용하는 사람
- 누가: 시험 공부하는 우리 아이 (화면에서는 애칭으로 부른다 — 애칭: (미정, 만들 때 여쭤봄))
- 어디서 들어오나: 엄마가 카톡으로 보낸 링크를 눌러서 (휴대폰 화면 기준으로 만든다)

## 3. 아이가 들어오자마자 보고 싶은 것
1. 남은 시험 일정 (다음 시험까지 며칠 남았는지)
2. 엄마의 오늘 응원 한마디
3. 오늘 기록 남기는 칸

## 4. 믿게 할 증거
- 해당 없음 (가족용 사이트). 대신 엄마가 직접 쓴 응원 한마디가 이 역할을 한다.

## 5. 누르게 할 버튼 하나
- 버튼 이름: 오늘 기록 남기기 (가칭)
- 누르면: 오늘 공부한 과목 + 기분 한 단어가 저장되고 칭찬 스티커가 하나 붙는다

## 6. 페이지 구성 (위에서 아래로, 1장)
1. 첫 화면 — 애칭 인사 + 다음 시험 D-day
2. 엄마의 오늘 응원 한마디
3. 남은 시험 일정 (날짜·과목 목록, 지난 시험은 흐리게)
4. 오늘 기록 남기기 — 공부한 과목 고르기 + 기분 한 단어 + 버튼
5. 칭찬 스티커판 — 기록한 날마다 스티커 하나, 지난 기록 목록

## 7. 기록 칸에서 받을 것
- 오늘 공부한 과목 (시험 과목 중에서 고르기, 여러 개 가능)
- 기분 한 단어
- 이름·연락처 등 개인정보는 받지 않는다

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 시험 일정(날짜·과목): (미정 — 만들 때 엄마가 알려 주기로 함)
- 오늘의 응원 한마디: (미정 — 엄마가 클로드에게 부탁해서 바꿈)
- 아이 애칭: (미정)
- 들어오는 방법: 카톡 링크

## 9. 이번에 넣지 않을 것
- 로그인·회원가입 (아이는 링크만 누르면 바로 들어온다)
- 엄마에게 알림 보내기 (메일·카톡 알림)
- 사진 올리기 (온라인 저장소가 필요해서)
- 엄마 전용 관리 페이지(/admin), 온라인 저장(Supabase)

## 10. 첫 화면 한 문장 후보
1. "[애칭]아, 오늘도 한 칸 채워 볼까?"
2. "다음 시험까지 D-[n]! 엄마가 응원해 💪"
3. "[애칭]의 시험기간, 엄마가 옆에 있어"

## 11. 다음에 할 것
- 엄마에게 알림 보내기
- 로그인·회원가입
- 사진 올리기
- 엄마도 기록을 볼 수 있게 온라인 저장 + 엄마 전용 페이지

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 발랄한 · 참고 디자인: 없음 — 클로드가 정함
- 휴대폰 화면 우선
- 기록 저장: 온라인 저장 아니요 → 아이 폰(브라우저) 안에만 저장. 엄마는 아이 폰으로만 볼 수 있다
- 시험 일정·응원 한마디 바꾸기: 엄마가 클로드에게 "오늘 한마디 바꿔 줘"라고 부탁 → 클로드가 고쳐서 다시 배포
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel
  - 공개 저장소라 누구나 코드를 볼 수 있으므로, 아이 실명·학교 이름은 넣지 않는다

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 시험 일정·애칭을 엄마에게 받는다
2. 스타일(색·글꼴)을 '발랄한' 분위기에 맞게 정하고 첫 화면부터 만든다
3. 기록 남기기 + 칭찬 스티커판을 만든다 (아이 폰 안에 저장)
4. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
5. 다 만든 뒤 한 번에 보고: 사이트 주소 · 확인 방법 · 응원 한마디 바꾸는 법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): GitHub·Vercel 로그인
